# Napalm — Henri de Canecaude

Responsive filmmaking portfolio, built with plain HTML and CSS. No build tools or paid services required.

## Publish on GitHub Pages

In this repository, open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, then **main** and **/ (root)**, and save.

The expected URL is https://napalmpr.github.io/napalm/ once GitHub finishes deployment. This address is not a claim that Pages has already been enabled.

## Edit

- `index.html`: biography, projects, email and links.
- `style.css`: typography, layout and colors.
- `assets/`: optimized copies of Henri’s supplied filmmaking stills.

The frame archive is not attributed to a specific film because the original stills did not identify their project. Add confirmed YouTube/Vimeo film links to the appropriate projects when available. No placeholder playback links are included.

## Local preview

Run `python3 -m http.server 8000` in this folder, then open http://localhost:8000.
